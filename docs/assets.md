# Asset provenance

The six SVG portraits in apps/web/public/art were created specifically for this implementation as vector illustrations. They are deliberately abstract style concepts, not photographic output or testimonials. They may be modified for this project; no third-party photos were copied. Replace with owned/licensed representative photographs before live selling.

Fonts are distributed through pinned @fontsource/fraunces and @fontsource/manrope packages and bundled by Vite; retain their license notices when redistributing built assets. Third-party package licensing remains governed by each dependency's included license. The source ZIP does not bundle node_modules or font binaries.
